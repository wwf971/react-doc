## Bare name, single match

Normal link: [database.md](database.md) resolves anywhere in the source.

With heading anchor: [object types](database.md#object-types)

## Bare name, multiple matches

[notes.md](notes.md) exists twice (here and under `sub/`), so clicking shows a
dropdown of candidates.

## Inline code as link

Just mentioning `frontend-store.md` in inline code becomes navigable.

## Obsidian style

## Non-md doc file

Links to non-md files in source also work: [sample.py](sample.py)

## Broken link

[missing.md](missing.md) is rendered as a broken link, not clickable.

## Inline source links

A sentence can open a source popup in place: see the
[collection sample script](/mdx-test/sample.py "inline-link") before continuing, or use the
explicit marker for [the same script source](/mdx-test/sample.py "inline-link:source").
Render mode compiles the target instead of showing its source text: read the
[notes document](/mdx-test/sub/notes.md "inline-link:render") without leaving this page.
A title that is not an exact marker keeps normal link behavior:
[ordinary titled link](/example/doc.md "just a title").

## External links unaffected

[fumadocs site](https://fumadocs.dev) opens normally, including with a marker-looking
title: [external inline-link title](https://fumadocs.dev "inline-link").
