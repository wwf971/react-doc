## Forms of a link

A link names a card, or one place of it ([A link to a place in a card](link-place.md)). Every link can be followed backwards too ([Backlinks](link-backlink.md)), so a card shows who points at it.

<!--renderComp=Anchor,id=when-->

## When to link

Link where the other card really helps: a prerequisite, a contrast, an example. A link to everything is a link to nothing.
