This document is not a file of the doc page folder. The page keeps it in the virtual root `~notes`, in `.doc-page/doc-managed/{id}--notes/`, named by its id; its path in the root, `guide/what-is-managed.md`, is in its record. It is read, linked, placed in the side panel and edited like any document: switch **Edit** on and change this paragraph.

It is kept in **mode text**: its file in the root is the text as written, so git shows a change of it as a change of a Markdown file.
