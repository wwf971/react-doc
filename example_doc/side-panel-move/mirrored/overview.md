---
title: Mirrored Overview
---

A file of `side-panel-move/mirrored/`, the source folder that the `Mirrored Folder` item of the sandbox mirrors. Its item is generated: it has a small file glyph before its name, follows the file, and is not renamed, moved or removed in the side panel. Add, rename or delete a file in the folder and its item follows; **Refresh** in the item's menu reads the folder again when the change was made where the file watcher does not see it.
